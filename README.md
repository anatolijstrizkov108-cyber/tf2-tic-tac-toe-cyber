# TF2 Tic-Tac-Toe // Cyber Edition

Консольные крестики-нолики в стиле **Team Fortress 2** с неоновой
киберпанк-палитрой, ИИ на минимаксе с альфа-бета отсечением и
«травма-тим» репликами после каждого раунда.

## Возможности

- 🎨 Неоновая ANSI-палитра (RED / BLU / CYAN / PINK).
- 🧠 Непобедимый ИИ: минимакс + alpha-beta pruning.
- 🎭 Рандомные TF2-шутки на победу, поражение и ничью.
- 📊 Счёт между раундами (RED / BLU / ничьи).
- 🎲 Жребий на старте каждого раунда — кто ходит первым.
- ⌨️ Выход по `q`, реванш по `д/н`.

## Требования

- Python **3.8+**
- Внешних зависимостей **нет** (только стандартная библиотека).

python "Team Fortress.py"
